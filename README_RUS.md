## 🎯 О проекте

**Medusa Next** — бескомпромиссный идейный перезапуск оригинального проекта [**Medusa**](https://github.com/bsu-digital-lab/medusa), очищенный от сгенерированного промптами спагетти-кода, контроллеров по 0 байт и логотипов с зелёным салатным листом.

В основе лежит простая философия: **приложение с расписанием должно показывать расписание**, а не DDoS-ить легаси PHP-сервер университета прямо со смартфона, высаживать батарею шейдерами с салютами и притворяться биржей волонтёров по перетаскиванию парт. Построено на **BLoC** поверх [**Medusa Backend**](https://github.com/shizamuru-dev/medusa-backend) — возвращает оригинального мифологического маскота и даёт чистую, мгновенную пользу.

## 🧬 Почему «Next»?

Этот репозиторий — возвращение к изначальной инженерной концепции **Medusa**:
- **Сначала бэкенд, а не клиентский DDoS**: тяжёлый парсинг HTML, ретраи и кэширование в Redis живут на сервере, а не внутри цикла `setState` на телефоне.
- **Функциональность важнее салютов**: никаких оверлеев с конфетти, костылей `--android-skip-build-dependency-validation` и непонятного комбайна внутри.
- **Настоящая Медуза**: проект назван в честь Горгоны, породившей *Пегаса* (СЭО БелГУ) — поэтому на иконке настоящая медуза, а не стоковый ботанический росток.

## Офлайн-кэширование

Состояния расписания автоматически сохраняются на диск через `hydrated_bloc`, а пользовательские настройки (выбранная группа, цветовая схема, избранное) хранятся локально в `shared_preferences`.

Если сеть или сервер временно недоступны, приложение мгновенно отрисовывает последний сохранённый снимок расписания без блокировки интерфейса.

## ✨ Ключевые возможности

- ⚡ **Мгновенный старт**: ноль блокирующих сетевых запросов в `main()` — кэшированные данные рендерятся сразу при открытии.
- 🧱 **Архитектура BLoC**: жёсткое разделение слоя данных, бизнес-логики и «глупых» UI-виджетов.
- 📅 **Умные недели и подгруппы**: плавная горизонтальная навигация по неделям и компактные аккордеоны подгрупп.
- 🏫 **Расписание аудиторий по запросу**: нажатие на любую аудиторию подгружает её актуальную занятость на неделю через API бэкенда.
- 💾 **Offline-First**: автоматическая персистентность стейта через `hydrated_bloc` для работы в метро и без связи.
- 🎨 **Чистый минималистичный UI**: 6 выверенных цветовых тем, включая настоящий OLED-чёрный, без тяжёлых шейдеров и просадок кадров.

## 🚀 Быстрый старт

### Требования

- **Flutter SDK**: `3.27+` (Dart `3.13+`)
- **Бэкенд**: запущенный инстанс [Medusa Backend](https://github.com/shizamuru-dev/medusa-backend)

### Локальный запуск

```bash
# 1. Клонируйте репозиторий
git clone [https://github.com/shizamuru-dev/medusa-next](https://github.com/shizamuru-dev/medusa-next)
cd medusa-next

# 2. Установите зависимости
flutter pub get

# 3. Запустите приложение (указав адрес вашего бэкенда)
flutter run --dart-define=API_BASE_URL=http://localhost:8080

```

### Сборка релизного APK

Чистая сборка из коробки — без костылей отключения tree-shaking и обхода проверки зависимостей:

```bash
flutter build apk --release --dart-define=API_BASE_URL=[https://medusa.glitched.network](https://medusa.glitched.network)

```

## 📡 Интеграция с бэкендом

Medusa Next выступает тонким, строго типизированным клиентом поверх REST-эндпоинтов **Medusa Backend**:

| Метод | Эндпоинт | Назначение |
| --- | --- | --- |
| `GET` | `/weeks?action=this_week` | Получение информации о текущей, прошлой и следующей учебных неделях |
| `GET` | `/groups/{id}/schedules/current` | Загрузка расписания текущей недели для выбранной группы |
| `GET` | `/groups/{id}/schedules?week=15` | Загрузка расписания на конкретную учебную неделю |
| `GET` | `/auditories/{id}/schedules` | Получение расписания конкретной аудитории по запросу |

## 🛠️ Разработка

### Структура проекта

```text
lib/
├── core/
│   ├── api/            # HTTP-клиент Dio, базовые настройки и интерцепторы ошибок
│   ├── di/             # Настройка DI-контейнера (get_it)
│   ├── storage/        # Обёртка над SharedPreferences (группа, тема, избранное)
│   └── theme/          # 6 цветовых схем и конфигурация OLED-тёмной темы
├── features/
│   ├── schedule/       # Основной модуль расписания группы
│   │   ├── data/       # Типизированные модели и ScheduleRepository
│   │   ├── bloc/       # ScheduleBloc, события и Hydrated-состояния
│   │   └── ui/         # Экран расписания, пейджер недель и карточки пар
│   ├── auditory/       # Модуль расписания аудиторий по запросу
│   │   ├── data/
│   │   ├── bloc/
│   │   └── ui/
│   └── settings/       # Выбор группы и переключатель тем
│       ├── bloc/
│       └── ui/
└── main.dart           # Точка входа, инициализация DI и HydratedStorage

```
